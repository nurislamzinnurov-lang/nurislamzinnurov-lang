## Что в проде

| Проект | Что делает | Стек |
|---|---|---|
| **signal-v2** | OSINT по юрлицам: сбор из госреестров → сигналы → scoring → письмо → прогрев ящика. Прод на VPS | Python · Flask · SQLite · Docker |
| **Warmbly** | Платформа холодных рассылок и прогрева ящиков: CRM, unified inbox, warmup-пулы | Go |
| **Autopost** | Автопостинг Telegram + Instagram: 7 рубрик, карусели, ~78 постов опубликовано автономно | Python |
| **blogery-media** | Витрина медиакитов блогеров: домен, приёмка качества сборки, покрыта тестами | JS · HTML/CSS |
| **Prompt2Exe** | «текст → exe»: воркер PyInstaller (15 МБ), CI на GitHub Actions, деплой на Amvera | Python |
| **InboxPulse** | B2B-рассылка: 3578 собранных лидов, ~1814 писем, ответы падают в CRM | Python |
